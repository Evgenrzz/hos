# Исправления в нормализаторе файлов

## Основные изменения:

### 1. Транслитерация кириллицы
- Добавлена функция `transliterate_cyrillic()` для перевода русских символов в латиницу
- Применяется при нормализации имени файла
- Пример: "игры матч" → "igry match"

### 2. Версия записывается ДО нормализации
- Функция `extract_version_from_filename()` извлекает версию из исходного имени файла
- В таблицу `file_tracking` записывается оригинальная версия (например, "1.8.3")
- Версия извлекается до применения нормализации

### 3. Правильное обновление поля apk-original
- Функция `format_filename_for_attachment()` форматирует имя для поля apk-original
- Убирает подчеркивания, заменяет на пробелы
- Восстанавливает точки в версии ("1 8 3" → "1.8.3")
- Пример результата: "[attachment=873:Dream Mania - Игры Матч 3 1.8.3.xapk]"

### 4. Проверка физического файла
- Добавлена функция `check_physical_file_exists()`
- Проверяет существование файла на диске
- Проверяет что это файл, а не папка
- Проверяет что размер файла больше 0
- Если файл отсутствует → перекачиваем заново

### 5. Улучшенная нормализация имени файла
- Убирает кириллицу и переводит в латиницу
- Убирает специальные символы (+, -, пробелы)
- Заменяет на подчеркивания
- Приводит к нижнему регистру
- Пример: "Dream+Mania+-+Игры+Матч+3_1_8_3.xapk" → "dream_mania_igry_match_3_1_8_3.xapk"

## Примеры работы:

### Исходный файл:
```
dream+mania+-+игры+матч+3_1_8_3.xapk
```

### После нормализации:
```
dream_mania_igry_match_3_1_8_3.xapk
```

### В базе file_tracking:
```
version: "1.8.3"
app_name: "Dream Mania - Игры Матч 3"
```

### В поле apk-original:
```
[attachment=873:Dream Mania - Игры Матч 3 1.8.3.xapk]
```

## Технические детали:

- Все извлечения версии и названия происходят ДО нормализации
- Физическая проверка файлов предотвращает ошибки
- Транслитерация поддерживает все русские символы
- Сохранена обратная совместимость с существующим кодом
